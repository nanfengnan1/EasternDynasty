# 幽州方格地图与武将卡牌：重做基线

2026-10-25。用户明确否定上一版画质、小地图与网格表现，要求全力学习 UI 制作并分析已有游戏。本文件覆盖与之冲突的旧研究建议；不会将旧版本“检查通过”解释为用户接受了美术质量。

## 已确认方向

1. 参考《率土之滨》的方格地图。保留等尺寸正方形逻辑地块，斜视投影下仍可直接识别每一格；资源、归属和选择都必须与格子对应。
2. 先做幽州，之后扩充其他区域。不能继续用缩小的九州天下占位图代表目标，也不能仅拉远相机冒充地图扩大。
3. 武将卡牌参考其人物主导的构图和信息层级，追求精细完成度。正式资产使用本项目原创或有授权素材。

## 上一轮为什么偏离

- 过度从地形升级宣传中归纳“连续地貌”，把方格的策略辨识弱化了。连续山河与清楚地块可以同时存在，地块必须作为交互和阅读的基础。
- 程序生成山石、树和房屋只验证了显示能力，形状、材质与光照仍是占位质量。
- 卡牌虽然接入了原画，卡框、星级位置、姓名排布、状态标记和详情构图没有充分对照真实卡牌界面。
- 玩法检查、截图成功和没有异常只证明功能可运行；它们不能证明美术质量达标。

## 下一样板的具体验收

### 地图

- 在正常操作视距下，每格边界连续且稳定；斜视形变由相机决定，不绘制不一致大小的假网格。
- 细格线、整格归属覆盖、选中强边/角标分别承担不同信息，不相互替代。资源图形的中心与实际可选 Land ID 一致。
- 农田、草场、石场、铁器生产点具有不同轮廓及完成度，不能靠随机散布几条线或同一种石块代替。
- 城池必须有门楼、墙体、建筑群层次和统一尺度；山、水、道路与资源格的可通行含义一致。
- 同一局部有近景资源格、中景城池、远景地形三档固定截图，检查材质、地块辨识、遮挡与帧时间。

用户随后指定本轮为 **40×40，共1600格**，覆盖原128×128提案。实现采用独立幽州布局；真实历史地理及城池位置须另行核对，不能将玩法布局称为考据地图。

### 武将卡牌

- 先精修一张可复用卡牌组件，覆盖普通、选中、上阵、锁定与抽取结果；再扩展角色数量。
- 对照实际卡牌列表，而不是把宣传海报当卡牌 UI。已查看的官方 2022 阵容图中，顶部是星级、左侧是阵营和纵向姓名、底部是紧凑数值；不同模式仍需分别核对。[原图所属官方公告](https://www.daisangoku.com/news/official/20221024/31170_1048138.html)
- 原创人物、卡框、角饰、底板与文字分层制作，星级/等级/阶数由游戏数据绘制，不烘焙进人物图。
- 头像和完整立绘使用独立取景。卡面要保住头饰、脸与关键身份剪影，并在真实显示尺寸下检查。
- 每轮给出旧图、参考图、当前客户端图和未解决差距；不能只用“更精美”“更高级”等形容词验收。

## 技术边界

旧地图宽高、地区、出生城和存档强耦合，扩大地块数前必须梳理。建议新幽州地图具有独立 mapId 与存档槽，保留现有 campaign.json；未来用地图标识加局部 ID 寻址。

不得为每格复制碰撞体和全部景物。绘制采用可见区域分块与共享资产，拾取由射线与网格求交。详细调用链、存档隔离和测试矩阵已保存于 [幽州迁移审查](../../ResearchLibrary/UI-Modeling/Youzhou-Migration.md)，其中128尺寸已被本轮40×40覆盖。

## 本轮“学习”的产出

学习应沉淀为可追溯的截图拆解、明确设计规范、可复用组件、项目资产和实际修改。增加爬取数量或代理数量本身不构成美术进步。本轮正在重做方格与卡牌参考分析、幽州迁移审查；本文件不是新客户端已实现的声明。
