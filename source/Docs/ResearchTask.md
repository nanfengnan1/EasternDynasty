## 本轮研究范围

1. 武将立绘：构图、剪影、服装、材质、身份识别，汉地、草原和东北文化的差异。
2. 武将卡牌与界面：立绘占比，星级、阶数、等级、技能、兵种的层级，配将与招募操作。
3. 沙盘地图：远中近景信息，连续地貌、山脉、河流、植被、城池、营地、资源地、领地归属与行军表现。
4. 对应 Unity 实现：模型与贴图清单、比例、分块、LOD、光照、文字和 UI 结构。
5. 原型改造顺序：先确定一个可评审的画面样板，再批量制作资源，保持现有玩法可运行。
