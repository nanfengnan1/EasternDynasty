2. **归城缺少图像入口。** 基线是标题右侧矩形文字按钮；原图右上是独立圆形定位控件。本轮依据已见圆形和空心水滴符号建立可编辑组件，44×44 触控范围内保留独立定位图像与“归城”文字，导出正常/悬停底片；图像和文字均触发原 `map.CenterHome()`。该项目功能适配不声称复制了原作定位菜单。
3. **坐标与图例挤在一行。** 基线坐标放在底部“领地/视野”之后。新稿把焦点坐标放在标题下形成上方位置识别；底部只保留领地、视野与 `S1 · 40×40`。文字使用实际 GUI 字体度量和边界检查，不烘焙动态数据。

**保留的差异：** 原图是横向更宽的世界缩略图，本项目仍用方形幽州40×40舆图；没有编造十三州数据或为了贴图拉伸地图。当前程序地图地形和动态几何未新增美术算法，本轮没有扩写 CitySceneRaster 或 HudLine。
