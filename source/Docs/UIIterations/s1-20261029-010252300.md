# 武将战法分栏详情页

本轮完成专业分层设计、Inkscape 实际导出和两张正式组件接入，按稿修改武将战法页。**UI 源码完成，运行观感和真实点击待发布者验收。** 没有启动 Unity、客户端或桌面操作，没有更新 Windows/APK。

## 参考、基线与三个差距

实际打开本轮新增 `Q07-JA-A003`：572×321 历史战法弹窗，来自 2021-02-26 的 17173 转载；截图日期、客户端、赛季均未知，`excludedFromS1=true`。采用其“共享标题、左侧图像、右侧效果、下方次级信息”构图，不引用其中技能数值。也实际打开官方 2022-04-10 `STZB-0467`（1793×1008）核对现有武将详情周边层级，保留现有大立绘与导航。真实路径、原图 SHA、来源 URL 和十份原文核验见 [RAG 审计](../../Validation/UIRound/s1-20261029-010252300/rag-audit.json)。新取得的图不等于新版 UI，按具体页面选择历史参考，没有把它称为当前 S1。

游戏基线为发布者 225 版 `smoke-card-skill.png`，分别为 1440×900 桌面和 1600×720 手机预览，路径与 SHA 见 [design-spec.json](../DesignUI/s1-20261029-010252300/design-spec.json)。两张均已实际查看，不能当成本轮运行图。

1. 基线是106高黑底标题、下方独立长段说明，再下一块学习面板。原图把图像与效果归在同一详情内。本轮合为带共享标题的完整详情页，图像列与效果列并排，正文从右侧88单位位置起排。
2. 基线自带/学习战法都使用程序线条圆章，主次图像相似。本轮自带战法使用96×96已有正式圆章和原尺寸66×36书册，下方独立类别文字；学习状态改成同轴横行，去掉重复徽记。书册是既有项目插图，不是该武将的官方专属战法图。
3. 基线标题与效果、学习状态没有一致列对齐，长段正文游离于标题底面外。本轮右侧效果与学习状态统一160单位起点，标题固定32高，原文按真实字体测高扩展容器；次级横栏与主详情相隔14单位，说明不烘焙、不截短，溢出继续滚动。

这是一个完整战法信息区的构图/图像/层级调整，不代表完整武将页或商业美术还原。没有添加未知战法类型、发动率标签、等级强化、拆解或伤害规则。
