## 实际 UI 修改

- 新增 `Runtime/MinimapAtlasRaster.cs`，根据真实 `world.lands` 在CPU绘制320×320地形底图。普通资源地采用低对比度地面与稀疏田纹；实际水域绘出河面和岸线，实际山地绘出峰形和明暗，三处桥梁保持真实位置/方向。没有使用整屏截图充当地形，也没有改变1600格规则、地图坐标或可通行性。
- `Runtime/MinimapPresentation.cs` 替换 `YouzhouPresentation.MiniMap` 的旧色块绘制。232×302的轻量底板、204×204舆图区、44高归城按钮与底部图例组成一块完整区域，保留主界面可见地图。城池改为带门洞/城垛的符号，主城放大并带独立名称签；领地逐帧从真实归属叠加，不会因数量相同而保留旧位置。
- 镜头视野由实际相机四角射线投影到地面，按地图边界裁切多边形；使用深色底线与浅色细线叠画，并保留中心点。方位“北”、领地/视野图例和实际焦点坐标独立排布。显示范围是相机地面覆盖，不是路径、可出征范围或已探索区域。
- 点舆图继续按实际矩形换算40×40焦点，“归城”仍调用原 `CenterHome`。只有可见、未被模态遮挡时登记 `minimap-area/map-home` 并接受输入；安全区与地图阻挡保持共享转换。`MapHudPresentation.HudLine` 仅增加可选线宽，原图标默认线宽不变；`EasternDynastyGame.OnDestroy` 释放生成纹理。
- 无Core/Application规则、存档字段、卡池或正式资源变更。原创程序图不是正式PNG导入；没有新增资产ID、修改旧meta或运行固定旧RAG导入器。
